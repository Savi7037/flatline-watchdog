# Flatline Watchdog

Telegram alerts for any trading bot that can send a web request. Know when yours stops, runs low on funds, starts failing or loses too much.

**In development, not live yet.** Founding pre-orders: [flatlinewatchdog.in](https://flatlinewatchdog.in)

This repository holds promo files only. It doesn't contain the product's code.
